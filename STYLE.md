# Styling gsuite-manager

## Name

- **Full name**: gsuite-manager
- **CLI command**: `gsm`
- **In prose**: "gsuite-manager" (lowercase, hyphenated)
- **Never**: "GSuite Manager", "Gsuite-Manager", "GSM" (conflicts with cellular standard)

## Pronunciation

- gsuite-manager: "gee-suite manager"
- gsm: "gee-ess-em" (the CLI command)

## Logo Usage

- Use the SVG from `docs/assets/logo.svg`
- Minimum size: 32px height
- Always include alt text: "gsuite-manager logo"

## Colors

- Primary: `#4285F4` (Google Blue)
- Secondary: `#F48C42` (Cloudflare Orange)
- Terminal: `#1E1E2E` (Catppuccin Mocha base)

## Writing About gsm

- "gsuite-manager automates Google Workspace + Cloudflare management"
- Emphasize: idempotent, tested, production-ready
- Target audience: Google Workspace admins managing multiple domains
- Positioning: "The CLI that replaces clicking through Admin Console + CF Dashboard"
